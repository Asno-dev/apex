# apex-ppt — Create PowerPoint Presentations

Generates Microsoft PowerPoint (.pptx) presentations from natural language descriptions using OfficeCLI.

## Usage

```
apex-ppt make a presentation on Q1 results
apex-ppt create a pitch deck for investors
apex-ppt generate a project status update slide deck
```

## Integration

Powered by OfficeCLI. Requires Microsoft Office installed on the system or Office 365 API access.
