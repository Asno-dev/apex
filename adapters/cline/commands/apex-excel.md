# apex-excel — Create Excel Spreadsheets

Generates Microsoft Excel (.xlsx) spreadsheets from natural language descriptions using OfficeCLI.

## Usage

```
apex-excel build a budget spreadsheet
apex-excel create a project tracker with milestones
apex-excel generate a monthly sales dashboard
```

## Integration

Powered by OfficeCLI. Requires Microsoft Office installed on the system or Office 365 API access.
