# apex-composio-status — Show Connected Tools

Displays all currently connected Composio tools and their authentication status.

## Usage

```
apex-composio-status
```

Shows:
- Connected tool names (e.g. Gmail, GitHub, Slack)
- Authentication status (connected/expired)
- Available actions per tool

## See Also

`apex-composio-setup` — Connect a new tool
`apex-composio-sync` — Force sync from backend
