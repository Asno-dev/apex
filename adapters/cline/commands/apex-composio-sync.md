# apex-composio-sync — Force Sync Composio Backend

Forces a synchronization from the Composio backend to refresh tool definitions, authentication states, and available actions.

## Usage

```
apex-composio-sync
```

Use this after:
- Connecting a new tool
- Revoking/renewing an OAuth token
- Tools not appearing after setup
- Authentication state changes

## See Also

`apex-composio-setup` — Connect a new tool
`apex-composio-status` — Show connected tools
