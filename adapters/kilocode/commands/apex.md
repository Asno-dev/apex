# /apex — APEX Mode Control
- `/apex team` — Team mode (default)
- `/apex select a,b` — Select mode
- `/apex off` — Disable
- `/apex status` — Show mode
- `/apex help` — Show help guide.
- /apex-team — Full team mode. All 10 agents work together end-to-end.
- `/apex status` — Show mode
