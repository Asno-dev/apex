# /apex — APEX Mode Control
- `/apex team` — Team mode (default). Routes to best agent, agents call peers dynamically.
- `/apex select a,b` — Select mode. Only listed agents active.
- `/apex off` — Disable APEX.
- `/apex status` — Show mode + active agents.
- `/apex help` — Show help guide.
