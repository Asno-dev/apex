# apex-docs — Create Word Documents

Generates Microsoft Word (.docx) documents from natural language descriptions using OfficeCLI.

## Usage

```
apex-docs create a report on Q2 earnings
apex-docs write a proposal for the new project
apex-docs generate meeting minutes template
```

## Integration

Powered by OfficeCLI. Requires Microsoft Office installed on the system or Office 365 API access.
