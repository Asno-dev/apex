# Requirements to Spec Protocol

1. **EXTRACT** user stories from description
   Format: As a [user type], I want to [action] so that [value]

2. **IDENTIFY** acceptance criteria per story (Given/When/Then)

3. **CLASSIFY** — Functional vs non-functional requirements

4. **FLAG** ambiguities — list every unclear requirement with a specific question

5. **SCOPE** — What's in MVP vs future?

6. **OUTPUT** — Complete structured spec in markdown, ready for engineering
