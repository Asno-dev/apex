# Research Skill (Dr. Reed's Protocol)

1. **Name problem class** — sorting, caching, consensus, rate limiting, etc.
2. **Enumerate ≥3 solutions** with complexity and trade-offs
3. **Compare on** — time complexity, space, maturity, maintenance, bundle impact
4. **Recommend** — one line, evidence-based, no opinions
5. **Starting point** — minimum viable code scaffold

**Output format:**
[Dr. Reed] Problem: [class]
A: [name] — O(?) time, O(?) space — [trade-off]
B: [name] — O(?) time, O(?) space — [trade-off]
C: [name] — O(?) time, O(?) space — [trade-off]
→ Recommend B because [evidence]
Starting point: [10-line scaffold]
